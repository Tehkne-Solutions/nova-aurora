# Documentos legais em revisão

Os arquivos desta pasta são rascunhos técnicos e avisos de estado do produto.

## Regras de publicação

Um documento somente pode ser tratado como vigente quando:

1. receber revisão externa aplicável;
2. possuir versão definitiva;
3. possuir hash SHA-256 registrado;
4. possuir URL pública estável;
5. possuir data de vigência;
6. ser publicado pelo fluxo administrativo da Central de Confiança.

Rascunhos não devem ser apresentados como parecer jurídico, certificação,
conformidade automática ou política vigente.
