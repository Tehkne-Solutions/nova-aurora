# Checklist de publicação de documento

- [ ] texto final aprovado;
- [ ] revisão externa registrada;
- [ ] versão definida;
- [ ] hash SHA-256 calculado;
- [ ] URL pública estável;
- [ ] data de vigência definida;
- [ ] documento anterior retirado quando aplicável;
- [ ] fluxo de novo aceite validado;
- [ ] comunicação ao usuário preparada;
- [ ] gate correspondente atualizado com evidência.

A conclusão técnica deste checklist não substitui a decisão dos responsáveis jurídicos
e operacionais.
